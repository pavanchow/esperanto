Esperanto

A small statically-typed language with type inference, built from scratch in Rust.

Lexer, parser, type checker, and interpreter, each short enough to read in one sitting. The part most build-your-own-language projects skip is the centrepiece here: a program that does not type-check never runs, and the checker infers the types you did not write down.
